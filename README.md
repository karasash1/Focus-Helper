# Focus Helper

A minimalist Pomodoro timer and To Do list web app built to stay focused and productive.

**Live Demo:** [Focus Helper](https://karasash1.github.io/Focus-Helper/)

## Features
- **Customizable Pomodoro Timer:** 25-minute default focus sessions with `+` and `-` buttons to adjust the timer by 1 minute per click.
- **Full Timer Controls:** Start, Pause, and Reset the countdown anytime
- **Sound effects:** sound effects including when finishing the task or the session.
- **To Do List:** Add tasks, mark them as finished, or delete them entirely.
- **Celebration & Motivation:** triggers a confetti animation, and displays encouraging messages every time you finish a task.
